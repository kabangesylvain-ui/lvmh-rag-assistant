# Politique de livraison LVMH

## Délais de livraison
- **France métropolitaine** : 2-3 jours ouvrés
- **Europe** : 4-5 jours ouvrés
- **International** : 7-10 jours ouvrés

## Frais de livraison
- Commande < 200€ : **15€**
- Commande ≥ 200€ : **gratuite**
- Livraison express : **+25€** (24h)

## Suivi de commande
Chaque commande reçoit un numéro de suivi par email.
Le suivi est disponible sur l'espace client LVMH.
